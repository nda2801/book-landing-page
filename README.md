# Trang Web Tĩnh Giới Thiệu Sách (Book Showcase)

Dự án trang web tĩnh giới thiệu về sách được xây dựng bằng **HTML5, CSS3, và Bootstrap 5.3**. Trang được thiết kế chuẩn responsive trên mọi thiết bị di động, tablet và desktop.

## Các phần hoàn thiện theo yêu cầu
1. **Header**: Menu điều hướng cố định (Sticky Navigation) tích hợp Scrollspy mượt mà.
2. **Book Overview**: Hero section giới thiệu bìa sách 3D, số liệu nổi bật và nút CTA.
3. **Author**: Giới thiệu về tác giả, hình ảnh, tiểu sử và mạng xã hội.
4. **Features**: 6 tính năng / nội dung chính nổi bật của sách với icon Bootstrap trực quan.
5. **Prices**: Bảng 3 mức giá ưu đãi (Ebook, Sách bìa mềm, Bản Combo Collector).
6. **Download**: Khối đọc thử tài liệu PDF/EPUB kèm form đăng ký nhận sách nhanh.
7. **Reader's Say**: Đánh giá thực tế từ độc giả kèm số sao và thông tin người đọc.
8. **Footer**: Điều hướng chân trang, mạng xã hội và thông tin liên hệ.
